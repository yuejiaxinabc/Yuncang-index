云仓（Yuncang）是面向中小制造、零售与贸易企业的开源仓储管理系统：商品、入库、出库、调拨、盘点、库位、批次效期、报表预警，一条命令部署到你自己的服务器，Web / 桌面 / 小程序三端共用同一套数据与权限。

Why Yuncang

数据在你自己手里，作业在离货最近的地方

自托管

服务端装在你自己的机器上，业务数据全部在本地 MySQL；不依赖任何云账号，内网也能跑。

三端一致

Web、桌面、小程序共用同一套账号、权限与单据；仓库电脑用桌面端，现场用手机扫。

开放接口 + SDK

17 个开放接口、API 密钥分级权限、JavaScript / Python / Go 三种 SDK，接自己的 ERP 不用改源码。

可控更新

自带更新中心：稳定 / 测试双通道、按百分比灰度、SHA256 校验，出问题把灰度调到 0 就停。

Modules

仓库日常需要的事，一套系统说清楚

01

商品主数据

编码、条码、单位、分类、安全库存；批量导入 Excel，支持批次与序列号管理。
02

入库作业

采购到货、退货入库、其他入库；货位四段坐标、批次号自动生成，支持直接过账。
03

出库作业

销售、领料、退货、调拨、维修、更换、其他七种类型，超可用量当场拦下。
04

仓库调拨

仓与仓之间转移库存，调出调入双向留痕，单据可追溯到人。
05

库存盘点

按仓库生成盘点单，逐项录实盘、自动算差异，结算后库存与账面同步。
06

库位管理

仓库→库区→货架→排→列→位多级建模，扫码定位，拣货路径清晰。
07

批次与效期

批次、生产日期、到期日全链路；临期预警与先进先出（FEFO）建议。
08

报表与预警

库存汇总、库存金额、低库存预警、出入库流水，支持按时间区间导出。

Deploy

一条命令，装进你自己的服务器

干净的 Linux（Ubuntu 22.04 / Debian 12，2 核 4G 起）。脚本自动装 Node 20、MySQL、nginx，建库建表、生成密钥、配置 systemd 与反向代理，装完浏览器打开就能用。

curl -fsSL https://yuejiaxin.ln.cn/install.sh | sudo bash

装完访问 http://你的服务器地址 设置管理员账号。完整步骤见 部署安装。

API & SDK

接自己的系统，不用改云仓源码

17 个开放接口覆盖商品、库存、批次、单据、报表与四类作业；API 密钥可绑定权限（scope）、仓库范围、IP 白名单与「仅 HTTPS」。官方 SDK 处理了鉴权、幂等键、429/5xx 退避重试、分页与错误码。

Update

更新怎么发到你手上

服务端每小时向更新中心上报一次心跳（版本、通道、端口、域名、主机名、出口 IP），控制台据此判断设备是否需要升级；桌面端与小程序按平台拉取清单，从最近的节点下载并校验 SHA256 后安装。

稳定通道

默认通道，所有设备收到；只推送验证过的版本。

测试通道

先小范围验证，设备在设置里切到测试通道即可收到，不影响其他人。

灰度发布

按百分比放量：先 10%，观察一天再全量；异常时调到 0 立刻暂停。

心跳上报哪些字段、能不能关，写在 隐私政策 第二节。

FAQ

常见问题

必须联网吗？

服务端在你自己的机器上，内网也能用；只有「检查更新」需要访问更新中心，离线部署可关闭心跳。

数据存在哪？

全部在你自己的 MySQL 里，云仓不收集业务数据。见 隐私政策。

能对接自己的系统吗？

可以。17 个开放接口 + 三种语言 SDK，见 开发者手册。

多人同时用会冲突吗？

密钥带权限与仓库范围，写操作带幂等键；并发建单不会重复扣减库存。

换服务器怎么办？

备份 MySQL 与上传目录即可迁移；桌面端和小程序在设置里改地址就能继续用。

要买什么许可证吗？

Apache 2.0 开源许可，自用与商用都免费。需要人帮忙部署可以看 部署服务。
