部署安装

按 CPU 架构选脚本：uname -m 输出 x86_64 用上面那条，aarch64 用下面那条。

x86_64

x86_64 / AMD64

Intel、AMD、普通云服务器（uname -m 为 x86_64）。

curl -fsSL https://update.yuejiaxin.ln.cn/install.sh | sudo bash
ARM64

ARM64 / aarch64

鲲鹏、倚天、Apple 虚拟化、ARM 云实例（uname -m 为 aarch64）。

curl -fsSL https://update.yuejiaxin.ln.cn/install-arm64.sh | sudo bash

armv7l（32 位 ARM）不支持：Prisma 没有 armv7 查询引擎。

Offline

离线安装（内网 / 无外网）

x86_64

tar xzf 云仓服务端-1.5.5-离线安装包.tar.gz
cd cloudwarehouse && sudo bash install.sh --offline

ARM64

tar xzf 云仓服务端-1.5.5-离线安装包-arm64.tar.gz
cd cloudwarehouse && sudo bash install.sh --offline

离线包下载：Yuncang-Update Releases

After Install

装完做什么

🌐

打开后台

http://服务器IP/，初始账号 admin / Admin@123，登录后立即改密。

🔒

配 HTTPS

设置 →「域名与 HTTPS」填域名一键申请证书；纯 IP 装机会自动配自签 HTTPS。

💾

备份与更新

设置 →「数据备份」立即备份 / 恢复 / 下载；「检查更新」自助升级。
