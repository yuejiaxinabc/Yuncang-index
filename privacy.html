Privacy

隐私政策

最后更新：2026-11-15

一句话

云仓不收集你的业务数据。业务数据全部在你自己的服务器上；我们唯一会收到的是服务端心跳与更新检查这类运行状态信息，且可以关闭。

一、桌面客户端与小程序在本地保存什么

内容位置说明
服务器地址本机配置文件你自己填的云仓地址
API 密钥 / 登录 Token本机配置文件桌面端用系统凭据加密（Windows DPAPI / macOS 钥匙串）；小程序用微信本地存储
界面偏好本机配置文件窗口位置、上次进入的页面

卸载客户端会删除上述全部内容；小程序删除后本地配置一并清除。

二、服务端心跳（会发送到更新中心）

为了让管理员知道「哪些机器在跑、是不是落后了版本」，云仓服务端启动后每小时向更新中心上报一次心跳。上报内容只有运行状态，不含任何商品、库存、单据或账号信息：

字段示例用途
installId安装时生成的随机串区分设备，不含用户身份
version1.5.3版本分布、落后提醒
channelstable / beta决定收到哪个更新通道
hostname服务器主机名控制台里认出是哪台机器
port / domain3000 / yc.example.com排障、点开即跳转
osLinux 5.15兼容性判断
ip服务端出口 IP控制台展示与在线判定（按请求来源记录）

可以关闭：不需要设备登记与版本管理时，在服务端配置中关闭心跳即可，业务功能不受影响；关闭后更新中心不会显示该机器。

三、更新检查

桌面端「检查更新」会请求更新中心与对象存储：携带平台、当前版本、设备标识与常规请求头（User-Agent），用于返回对应平台的清单并测速。不上传任何业务数据，也不读取你的数据库。

四、我们不做什么

  • 没有埋点、没有行为分析、没有广告 SDK；
  • 不上传崩溃日志（桌面端崩溃只写本机日志文件）；
  • 不读取或同步你的商品、库存、单据、账号数据；
  • 不把密钥、密码、令牌写进任何日志或上报内容。

五、服务端日志

服务端会在本机保存访问日志与错误日志（含请求路径、状态码、来源 IP、耗时），用于安全审计与排障。日志保存在你自己的服务器上，保留周期由你设置；我们无法访问。

六、第三方服务

场景涉及方传输内容
安装包与更新下载对象存储 / CDN下载请求与常规访问日志
文档与官网GitHub Pages页面访问日志
版本心跳项目自建更新中心上文第二节所列运行状态

七、你的控制权

  • 删除密钥：立即失效，相关客户端无法再访问；
  • 关闭心跳：不再上报设备状态；
  • 卸载客户端：本机配置与缓存一并删除；
  • 删除数据：业务数据在你自己的数据库里，由你直接管理。

八、代码签名

桌面安装包参与 SignPath Foundation 开源项目签名计划；macOS 版在获得 Apple 开发者证书后启用签名与公证。签名仅证明安装包来源与完整性。

九、联系

隐私相关问题通过 GitHub Issues 反馈；涉及数据删除请说明部署环境与设备标识。
