关于云仓

让仓库的数据留在自己的服务器上。

这是什么

云仓（Yuncang）是一套自托管的仓储管理系统。商品、入库、出库、调拨、盘点、货位、批次效期、报表预警在同一套数据里，Web 主控台、桌面客户端、微信小程序三种作业方式共用同一套权限。

面向谁

中小制造、零售与贸易企业。不需要买订阅，不需要把库存数据交给第三方，装在自己的服务器或虚拟机里即可。

技术栈

Next.js 14 + TypeScript + Ant Design 5 + Prisma + MySQL；桌面端 Electron；小程序原生；SDK 提供 JavaScript / Python / Go 三种实现。
