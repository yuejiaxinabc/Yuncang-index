更新通道

Stable 稳定通道

默认通道，所有设备收到。只放验证过、跑满一周的版本。

Beta 测试通道

先小范围验证。设备在设置里切到测试通道即可收到，不影响其他人。

灰度发布

按百分比放量：先 10%，观察一天再全量；异常时把百分比调回 0，立刻暂停。

升级方式

服务端

后台「系统设置 → 版本更新」检查；或按 部署安装 里的升级命令执行。升级前建议先备份数据库。

桌面端

设置 → 检查更新：自动探测最近下载源、校验 SHA256 后安装。也可直接下载新安装包覆盖安装，配置保留。

小程序

随微信版本自动生效，无需手动升级；发现缓存未更新，下拉刷新或删除小程序重进。

校验安装包

每个安装包都提供 SHA256，下载后核对一遍再安装：

# Windows PowerShell
Get-FileHash .\Yuncang-Setup-0.6.2-x64.exe -Algorithm SHA256

# macOS
shasum -a 256 Yuncang-0.6.2-arm64.dmg

校验值同时写在更新中心返回的清单里（latest.sha256），客户端安装前会自己比对。
