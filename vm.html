虚拟机镜像

系统、数据库、云仓都打包好了，导入开机即用，不用装依赖。

Download

按宿主架构选镜像

宿主是 Intel / AMD 选 x86_64，宿主是 ARM（Apple 芯片、鲲鹏、倚天）选 ARM64。镜像与宿主架构必须一致。

两套镜像的系统版本不同：ARM 镜像内置云仓 1.5.3，x86 镜像内置 1.5.2。 开机后在面板「设置 → 检查更新」升到最新稳定版 1.5.5 即可，数据不受影响。

x86_64 镜像

Intel / AMD 平台：VMware、Proxmox、KVM、Hyper-V

7.9 GB云仓 1.5.2开机即用
下载 VMDK（VMware） 下载 QCOW2（云主机）

VMDK 给 VMware 用；QCOW2 给云主机、KVM、Proxmox、UTM 用。

ARM64 镜像

Apple 芯片、鲲鹏、倚天、ARM 云主机

12.2 GB云仓 1.5.3开机即用
下载 VMDK（VMware） 下载 QCOW2（云主机）

VMDK 给 VMware 用；QCOW2 给云主机、KVM、Proxmox、UTM 用。

镜像内已含 Ubuntu 22.04、Node 20、MySQL 8 与云仓本体（ARM 1.5.3 / x86 1.5.2），首次开机自动初始化数据库。 文件大小 ARM 12.2 GB、x86 7.9 GB，建议给虚拟机预留 30 GB 以上磁盘。

Steps

导入与开机

1️⃣

导入镜像

VMware：文件 → 打开 → 选 .vmdk。云主机 / KVM / Proxmox：上传 .qcow2 到存储后挂载启动。UTM：新建虚拟机 → 选 QCOW2。

2️⃣

分配资源

CPU 2 核起，内存 4 GB 起，磁盘按镜像大小留 20 GB 余量。网络用 NAT 或桥接。

3️⃣

开机访问

开机后终端会显示访问地址；浏览器打开 http://虚拟机IP/，账号 admin / Admin@123，登录后改密。

Notes

说明

默认配置

系统 Ubuntu 22.04 · Node 20.18.1 · MySQL 8 · 云仓 1.5.3，服务名 cloud-warehouse，端口 9958，nginx 反代 80。

改远程访问

如需外网访问，进系统后配域名与证书：面板「设置 → 域名与 HTTPS」，或直接跑 bash /opt/cloud-warehouse/scripts/apply-domain.sh。
