Developer Manual

云仓开发者手册

把云仓接进你自己的系统：开放接口、API 密钥、多语言 SDK、错误码、更新协议与心跳机制。业务操作说明见 用户手册。

1. 鉴权

开放接口统一前缀 /api/v1/open，用 API 密钥鉴权：

Authorization: Bearer yc_live_你的密钥

密钥在云仓后台「设置 → API 管理」创建，可绑定：scope（能做什么）、仓库范围（能看哪些仓）、IP 白名单、仅 HTTPS、每分钟调用上限。密钥明文只显示一次。

不要把密钥打进前端或小程序包

小程序、网页里硬编码的密钥等于把仓库权限交给终端用户。终端场景请自建一层中转，或只发只读、限仓的密钥。

常用 scope

product:read · inventory:read · warehouse:read · stock:read · stock:write · order:read · lot:read · report:read

3. 请求约定

分页

所有列表接受 page、pageSize（上限 200~500 视接口），返回 { items, total }。

幂等

写接口自动/显式带 Idempotency-Key，同一 key 重复提交只落一单；不同请求体复用同一 key 会返回冲突。

时间

统一 ISO 8601 字符串（2026-11-15T10:00:00Z），区间查询用 from / to。

重试

429 与 5xx 可退避重试；写操作重试务必沿用同一幂等键。

错误码

HTTPcode含义与处置
401KEY_INVALID密钥无效/停用/过期，或 IP 不在白名单，去后台重新生成
403SCOPE_DENIED密钥缺该操作的 scope
403HTTPS_REQUIRED密钥要求 HTTPS，改域名 + 证书
403IP_NOT_ALLOWED出口 IP 不在白名单
409IDEMPOTENCY_CONFLICT同一个 key 用了不同请求体
429—超出每分钟上限，退避后重试
5xx—服务端异常，可重试；持续失败看服务端日志

4. SDK

官方 SDK 覆盖三种语言，接口命名与能力一致：地址归一化、写操作幂等键、429/5xx 退避重试、错误码翻译、自动翻页、货位四段编码。

JavaScript / TypeScript（Node、浏览器、微信小程序）

npm i yuncang-sdk
import { Yuncang } from 'yuncang-sdk';
const yc = new Yuncang({ baseUrl: 'https://yc.example.com', apiKey: process.env.YC_KEY });

const me = await yc.me();
const inv = await yc.inventory.list({ warehouseId: 1, pageSize: 200 });
const res = await yc.stockIn.create({ warehouseId: 1, autoPost: true, items: [{ productId: 12, quantity: 20 }] });

Python

pip install ./python

from yuncang import Client, Credential, StockInRequest, StockItem
c = Client(Credential("yc_live_xxx", "https://yc.example.com"))
print(c.me()["name"])
c.stock_in(StockInRequest(warehouse_id=1, auto_post=True, items=[StockItem(product_id=12, quantity=20)]))

Go

go get github.com/yuejiaxinabc/Yuncang-SDK/go

c := yuncang.MustNewClient(yuncang.Credential{APIKey: "yc_live_xxx", BaseURL: "https://yc.example.com"}, yuncang.Options{})
me, err := c.Me(context.Background())

源码与示例：Yuncang-SDK。小程序版打包在 dist/miniprogram/index.js，会自适配 wx.request。

5. 更新协议（manifest v2）

客户端先拿平台清单，再按测速挑源下载，最后校验 SHA256。清单结构：

{
  "schema": 2,
  "product": "yuncang-desktop",
  "channel": "stable",
  "latest": {
    "platform": "win-x64",
    "version": "0.6.2",
    "minVersion": "0.4.0",
    "mandatory": false,
    "notes": "本版本修复了\n1. …",
    "size": 85828393,
    "sha256": "…",
    "sources": ["https://…/win-x64.exe", "https://…/win-x64.exe"],
    "rollout": { "percent": 100 }
  }
}

字段约定：platform 取 win-x64 / mac-arm64 / mac-x64；rollout.percent 控制灰度（0 暂停，100 全量）；sources 给多个地域地址，客户端按 HEAD 测速选最快。

6. 心跳与设备可见性

服务端每小时向更新中心上报一次心跳，用于版本分布、落后提醒与在线判定。上报内容：

字段示例用途
installId随机生成的设备标识区分设备，不含用户信息
version1.5.3版本分布、落后判断
channelstable / beta决定收到哪个通道的更新
hostname仓库服务器主机名控制台展示，便于认机器
port / domain3000 / yc.example.com排障与跳转
osLinux 5.15兼容性判断
可以关掉

不需要版本管理时，在服务端配置里关闭心跳即可，云仓业务功能不受影响。详见 隐私政策。

7. 构建与签名

npm ci
npm run smoke        # 18 项自检
npm run dist:win     # Windows 安装包
npm run dist:mac     # macOS dmg（arm64 + x64）
npm run dist:appx    # MSIX（上架 Microsoft Store）

Windows 安装包参与 SignPath Foundation 开源签名计划（详见仓库 .github/workflows/sign-windows.yml）；macOS 需要 Apple Developer ID 证书 + notarize 才能消除 Gatekeeper 提示。
