Open API

接口总览

商品、库存、入出库、调拨、盘点、仓库、货位、报表共 30 个接口；密钥按 scope 与仓库授权，写操作支持幂等键。

# 鉴权
Authorization: Bearer <api_key>

# 读
GET /api/v1/open/products?page=1&pageSize=20
GET /api/v1/open/inventory?warehouseId=1

# 写（带幂等键，重复提交不会重复入库）
POST /api/v1/open/stock-in
Idempotency-Key: 8f2c…
SDK

三种语言

🟨

JavaScript

npm i yuncang-sdk

TypeScript 类型完整，支持 ESM 与 CJS。

🐍

Python

pip install yuncang-sdk

3.8+，同步客户端。

🐹

Go

go get github.com/yuejiaxinabc/Yuncang-SDK/go@v1.1.1

Go 1.21+。

Example

调用示例

JavaScript

import { createClient } from 'yuncang-sdk';

const c = createClient({
  baseUrl: 'https://wms.example.com',
  apiKey: 'YOUR_KEY'
});

const list = await c.request('products.list', { page: 1 });

Python

from yuncang import Client, Credential

cred = Credential(api_key="YOUR_KEY",
                base_url="https://wms.example.com")
c = Client(cred)

print(c.inventory, c.locations)
