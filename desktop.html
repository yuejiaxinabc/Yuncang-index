First Run

第一次打开

1 · 填服务器地址

形如 https://wms.example.com，可带端口。

2 · 填 API 密钥

后台「设置 → API 管理」创建，明文只显示一次。

3 · 授权范围

能操作哪些仓库由密钥的 scope 与授权仓库决定。

被系统拦截

Windows「更多信息 → 仍要运行」；macOS「系统设置 → 隐私与安全性」允许一次。

Features

桌面端能做什么

📥

入库 / 出库

七种出库类型、多种入库来源，货位四段坐标，超可用量当场拦。

🔀

调拨 / 盘点

仓间调拨双向留痕；盘点单逐项录实盘，系统算差异。

🖨️

扫码与打印

扫码枪直接扫，标签打印对接打印机，长时间作业不掉线。

云 Yuncang

自托管的开源仓储管理系统，Web / 桌面 / 小程序三端一致，数据留在自己的服务器。
