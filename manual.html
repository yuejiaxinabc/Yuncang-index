User Manual

云仓用户手册

面向仓库管理员与作业人员：从装好系统到每天怎么用。开发者请看 开发者手册。

阅读顺序

第一次部署 → 第 1 节；第一次登录 → 第 2 节；每天要做的事 → 第 3 节；遇到问题 → 第 6 节。

1. 安装

1.1 服务端（一台 Linux 机器）

curl -fsSL https://yuejiaxin.ln.cn/install.sh | sudo bash

脚本会装好 Node 20、MySQL、nginx，建库建表、生成密钥、配置 systemd 与反向代理。装完浏览器打开服务器地址即可。要求：Ubuntu 22.04 / Debian 12 及以上，2 核 4G 起。

1.2 桌面客户端（Windows / macOS）

从 桌面客户端 页下载对应平台的安装包：Windows x64、macOS Apple 芯片、macOS Intel。安装后第一次打开填两项：服务器地址（如 https://yc.example.com）与 API 密钥（云仓后台 → 设置 → API 管理 生成），测试通过即保存，之后双击图标直接进工作台。

1.3 微信小程序

用手机号或账号密码登录（与网页端同一套账号）。注意公众号后台需要把云仓域名加入「request 合法域名」。

2. 第一次登录后要做的四件事

① 建仓库

系统设置 → 仓库管理 → 新增，填编码与名称；按需设置库区、货架、排、列、位层级，用于生成四段货位编码。

② 建商品

商品管理 → 新增，或批量导入 Excel（表头：编码、名称、条码、单位、分类）。启用批次看效期，启用序列号看单件追溯。

③ 配账号与角色

系统设置 → 用户管理：管理员、仓管、只读三种角色；可限定某个账号只能操作指定仓库。

④ 生成 API 密钥

设置 → API 管理 → 新建，勾选需要的权限（scope）与仓库范围。密钥明文只显示一次，丢了只能重建。

3. 日常作业

3.1 入库

  1. 选仓库 → 选类型（采购入库 / 退货入库 / 其他入库）→ 选供应商（可选）。
  2. 扫商品条码或搜索加行；数量、成本价、批次号（桌面端自动生成，如 B20261115-A1）、放置货位（四段：货架-排-列-位）。
  3. 勾选「直接入账」提交后库存立即增加；不勾只生成草稿单，稍后过账。

3.2 出库

七种类型：销售、领料、退货、调拨、维修、更换、其他。加商品时系统会显示该仓可用量，填超了在提交前就拦住。库存不足时服务端会拒绝过账，单据保留为草稿并给出原因。

3.3 调拨

选调出仓与调入仓，加商品与数量。调拨不改变总库存，只改变归属；两个仓库都会留流水。

3.4 盘点

  1. 盘点页选仓库，生成盘点单（默认带出该仓所有在库商品）。
  2. 逐项录实盘数，系统自动算差异（实盘 − 账面）。
  3. 全部录完后点「结算」，库存按实盘数校正，差异写入流水。
  4. 桌面端可在生成盘点单后导出 Excel 盘点表，现场填完再回后台录入。

3.5 库存查询与单据记录

库存查询支持按仓库、商品关键词过滤，显示在库、可用、锁定数量；单据记录可按类型与时间区间检索，点开看明细与操作人。

4. 权限是怎么起作用的

一句话

界面上出现哪些作业，由你登录账号的角色决定；桌面端与 SDK 能做什么，由那把 API 密钥勾选的权限决定。两者互不替代。

管理员

全部模块 + 系统设置 + 用户与密钥管理。

仓管

入库、出库、调拨、盘点、库存查询；不能改系统配置。

只读

只能查库存与单据，不能建单。

密钥权限（scope）常见组合：product:read、inventory:read、warehouse:read、stock:read、stock:write、order:read、lot:read。写作业需要 stock:write，桌面端还会额外要求 warehouse:read 与 product:read 以便带出仓库与商品。

5. 更新、备份与卸载

5.1 更新

服务端：管理员在「系统设置 → 版本更新」里检查并安装，或在更新通道里切到测试版先验证。桌面端：设置 → 检查更新，自动探测最近下载源、校验 SHA256 后安装。小程序：随微信版本热更新，无需操作。

5.2 备份

# 建议每天一次，保留 14 天
mysqldump --single-transaction -u root -p cloud_warehouse | gzip > /backup/cw-$(date +%F).sql.gz

5.3 卸载

桌面端在设置页点「卸载云仓」，或从 Windows「设置 → 应用」卸载；卸载会一并删除本机配置（服务器地址与密钥）、缓存与快捷方式。服务端卸载见 部署安装 页末尾。

6. 常见问题

库存和实际不一致

先看单据记录里有没有未过账的草稿单；再对最近一次盘点做一次小范围复盘。盘点结算会以实盘为准校正。

出库提示库存不足

可用量 = 在库 − 已锁定。检查是否有待出库单占用了库存，或该商品在别的仓库。

桌面端提示密钥失效

密钥被删除、过期或 IP 不在白名单。到云仓后台重新生成，或把当前出口 IP 加进白名单。

提示要求 HTTPS

该密钥开启了「仅 HTTPS」策略。给服务器配域名与证书，或让管理员放行内网网段。

导入 Excel 没反应

表头要包含「编码、名称」（或 code、name），第一行是表头；xlsx 与 csv 都支持。

忘记管理员密码

在服务器上执行重置脚本，或用另一个管理员账号在用户管理里重置。
