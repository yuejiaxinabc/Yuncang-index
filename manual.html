用户手册

上手要用的流程都在这里。

📋

商品建档

编码、名称、单位、分类必填；条码、规格、品牌、安全库存可选。批量导入用 Excel 模板，表头与系统一致。

📥

入库

选仓库与货位 → 加商品行 → 填数量与批次 → 提交。可直接过账，也可先存草稿。

📤

出库

选类型（销售 / 领料 / 退货 / 调拨 / 维修 / 更换 / 其他）→ 选商品 → 超出可用量当场拦下。

🔀

调拨

选调出仓与调入仓 → 加商品 → 提交。调出调入双向留痕，单据可追溯到人。

🧮

盘点

按仓库生成盘点单 → 逐项录实盘 → 系统算差异 → 结算后库存与账面同步。

📊

报表

库存汇总、库存金额、低库存预警、出入库趋势；按时间区间筛选并导出。

Admin

管理员常用

用户与角色

角色决定能看哪些菜单，仓库范围决定能操作哪些仓库；两层同时生效。

安全设置

可开启两步验证；连续登录失败会锁定，密码强度有校验。

数据备份

设置 →「数据备份」：立即备份、恢复、下载、设置保留策略。

域名与证书

设置 →「域名与 HTTPS」：填域名一键申请证书，也可粘贴自有证书。

常见问题

登录报验证码错误？点验证码图片刷新，注意大小写。

导入 Excel 报表头不匹配？用系统里的模板导出，别改列顺序与表头文字。

出库提示库存不足？检查所选仓库与货位是否有可用量，批次是否选错。

面板点更新报错？确认服务以 cloudwarehouse 用户运行、backups/update-work 可写；或直接跑 install.sh --upgrade。
